# CodeAlpha FAQ Chatbot 🤖

**Intern: Mahrukh Baloch | BSIT MNSUAM | AI Internship - Task 2**

## 📌 Description
An AI-based FAQ Chatbot for CodeAlpha that answers frequently asked questions using keyword matching and NLP basics. Built entirely on Android using Pydroid 3.

This chatbot can handle queries about CodeAlpha internship, certificate, tasks, duration, and more with instant responses.

## ✨ Features
- Responds to 10+ FAQs (hello, what is codealpha, duration, certificate, tasks, etc.)
- Keyword-based matching - works offline
- User-friendly console chat
- Handles invalid queries gracefully
- Exit with 'bye'

## 🚀 How to Run
1. Install Pydroid 3 from Play Store
2. Copy `chatbot.py` file
3. Run: `python chatbot.py`
4. Try inputs:
   - hello
   - what is codealpha
   - internship duration
   - certificate
   - tasks
   - bye

## 🧠 Tech Stack
- Python 3
- NLP - Keyword Matching
- Dictionary-based FAQ Database
